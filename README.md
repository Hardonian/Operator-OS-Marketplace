Operator OS is a self-hosted founder/operator cockpit: SQLite-backed metrics, plain-English command-center views, and deterministic JSON APIs for external connectors.

Live local docs: `/mnt/c/Users/scott/Desktop/startup_ops_console/`

## What’s included

- SQLite-backed business memory + metrics store
- JSON read/write APIs under `/api/`
- Workspace-normalized entity feeds for CRM, billing, and support connectors
- Revenue, GTM, lead, pricing, and pilot playbooks
- Local-first browser dashboard
